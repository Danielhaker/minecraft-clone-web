# BlockWorld 🧱

Un juego de bloques inspirado en Minecraft, desarrollado con Three.js.

## Características

- Generación de mundo básico
- Controles de primera persona
- Renderizado 3D con Three.js
- Diseño responsivo

## Controles

- Clic para bloquear el cursor
- WASD: Moverse
- Ratón: Mirar alrededor

## Instalación

1. Clonar repositorio
2. Abrir `index.html` en un navegador moderno

## Tecnologías

- Three.js
- JavaScript moderno
- HTML5
- CSS3
